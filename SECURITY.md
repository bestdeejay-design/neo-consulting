# Security Policy

## Reporting a vulnerability

This repository contains a static landing page: HTML, CSS, and browser-side
JavaScript. There is **no server-side code, database, or user authentication**,
so the attack surface is limited. Still, if you find a security issue —
for example XSS via injected content, a tracking script, or a broken
dependency in generated assets — please report it privately.

**Do not open a public issue for vulnerabilities.** Instead, contact the
maintainer at [bestdeejay-design@users.noreply.github.com](mailto:bestdeejay-design@users.noreply.github.com)
or use GitHub Security Advisories:
`https://github.com/bestdeejay-design/neo-consulting/security/advisories`

Please include:
- the affected file and version (commit hash)
- a minimal reproduction
- impact description

## Supported versions

| Version | Supported |
|---|---|
| `main` | ✅ |

## Response

We aim to acknowledge reports within 5 business days and publish a fix as
soon as it is verified.
