# DECISIONS — Решения по проекту (ADR-lite, L1)

> **RU:** L1-уровень решений. Вместо полного набора ADR — один сводный файл с
> ключевыми решениями, их контекстом и последствиями. Формат упрощён от ADR-000.

## D-001 — Статический HTML/CSS/JS без сборщиков

- **Status:** Accepted · **Date:** 2026-08-13 · **Owner:** исполнитель
- **Context:** лендинг из 14 блоков, без бэкенда и динамики сервера. Сборщики
  (Vite/Webpack) добавляют зависимости и шаг сборки, не нужные для статики.
- **Decision:** пишем чистый HTML/CSS/JS, запуск через `python3 -m http.server`.
- **Consequences:** проще публикация на GitHub Pages; нет npm-зависимостей.
  Минус: без модульной сборки JS держим в одном `js/main.js`.

## D-002 — Локальные изображения в `assets/img/`

- **Status:** Accepted · **Date:** 2026-08-13 · **Owner:** исполнитель
- **Context:** бриф требует ноль внешних URL и тестовую графику (аватары, офис, OG).
- **Decision:** все картинки — локальные файлы в `assets/img/`, генерируются скриптом.
- **Consequences:** сайт автономен, индексируется офлайн; OG 1200×630 собирается
  скриншотом hero после финальной вёрстки.

## D-003 — Контент строго на русском, первым языком

- **Status:** Accepted · **Date:** 2026-08-13 · **Owner:** исполнитель
- **Context:** ЦА — российские ИП/ООО, бриф на русском, тон «мы/вам».
- **Decision:** весь текст сайта на русском; технические идентификаторы (OG, JSON-LD,
  `id` секций) — латиницей по стандартам.
- **Consequences:** понятно ЦА; SEO под русскоязычные запросы.

## D-004 — Публикация на GitHub Pages из main/root

- **Status:** Accepted · **Date:** 2026-08-13 · **Owner:** исполнитель
- **Context:** нужен бесплатный хостинг статики с HTTPS и простым деплоем.
- **Decision:** репозиторий `bestdeejay-design/neo-consulting`, Pages из ветки
  `main`, корень (`/`).
- **Consequences:** деплой = push в main; нет CI-конфигурации. Минус: нет
  собственного домена (вне скоупа).

## D-005 — Лицензия MIT

- **Status:** Accepted · **Date:** 2026-08-13 · **Owner:** исполнитель
- **Context:** открытый репозиторий, требуется явная лицензия для community health.
- **Decision:** `LICENSE` MIT, владелец `bestdeejay-design`, 2026.
- **Consequences:** максимальная свобода повторного использования.

## D-006 — Одностраничная структура лендинга

- **Status:** Accepted · **Date:** 2026-08-13 · **Owner:** исполнитель
- **Context:** 14 блоков брифа — это один просмотр, без разделения на страницы.
- **Decision:** один `index.html`, навигация по якорям (`#section`).
- **Consequences:** простая SEO-структура (одна страница + sitemap из 1 URL);
  якоря проверяются в TEST_PLAN T11.

## D-007 — Подход design-taste с токенами

- **Status:** Accepted · **Date:** 2026-08-13 · **Owner:** исполнитель
- **Context:** нужен премиальный, не «AI-шаблонный» вид при статике и Lighthouse ≥ 90.
- **Decision:** фаза Design Read → токены → uniqueness gate → реализация; все цвета
  в `:root`, ноль raw-hex вне токенов (проверка `meta_audit.py`).
- **Consequences:** единая палитра, лёгкая правка; контраст WCAG ≥ 4.5:1 по дизайну.
