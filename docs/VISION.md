# VISION — Видение продукта

> **RU:** видение продукта — «зачем»: для кого, какую проблему решаем, чего
> сознательно НЕ делаем. Одна страница, живёт весь жизненный цикл проекта.

## Vision statement

Статический одностраничный сайт-лендинг для ООО «НЕО КОНСАЛТИНГ» — бухгалтерского
аутсорсинга в Санкт-Петербурге. Сайт за один просмотр объясняет предпринимателю без
штатного бухгалтера, почему стоит отдать учёт нам, и ведёт к заявке.

## Problem statement

ИП и ООО на УСН ведут учёт сами или нанимают случайных исполнителей. Растёт риск
штрафов, теряется время на отчётность, нет понятного ценника. Готовых объяснений
«что именно мы делаем и сколько это стоит» у компании не было. Сайт закрывает этот
разрыв: прозрачные услуги, тарифы и гарантии в одном месте.

## Target audience

- **Основная (ЦА):** ИП и ООО на УСН без штатного бухгалтера, от 0 до ~20 сотрудников,
  владельцы, которые сами ведут учёт или устали от фрилансеров.
- **Вторичная:** растущий бизнес, которому нужна смена исполнителя; компании,
  проверяющие надёжность подрядчика по юридическим данным (ОКВЭД, дата основания).

## Value proposition / differentiation

- **УТП:** локальная петербургская компания с фиксированными тарифами на УСН-учёт,
  открытыми гарантиями и прямым контактом с директором. Без запутанных договоров и
  без давления продать «дороже».
- **Против конкурентов:** крупные агентства берут абонентку без прозрачности; фрилансеры
  не дают гарантий. Мы показываем цену, объём и ответственность на одной странице.

## Product principles

1. Контент строго по брифу заказчика — никаких выдуманных фактов.
2. Тон «мы/вам»: уверенно, без давления, на русском.
3. Один экран решает вопрос — без лишних шагов до заявки.
4. Всё проверяемо: каждый блок и метрика имеют критерий приёмки.

## Scope

| In scope | Out of scope (explicitly) |
|----------|---------------------------|
| 14 блоков лендинга по брифу | Личный кабинет клиента |
| Статический HTML/CSS/JS без сборки | Бэкенд, база данных, CMS |
| SEO-комплект (title, OG, JSON-LD, sitemap) | Рекламные кампании, контекст |
| Форма заявки через mailto | Онлайн-оплата, авторизация |
| Публикация на GitHub Pages | Собственный домен и хостинг |

## Long-term success criteria

- Сайт отвечает 200 на GitHub Pages, индексируется по запросам «бухгалтерское
  сопровождение СПб», «бухгалтер УСН».
- Посетитель за 1 просмотр видит цену и отправляет заявку через контактную форму.
- Lighthouse mobile + desktop ≥ 90 (категории Performance, Accessibility,
  Best Practices, SEO) стабильно держится после публикации.
